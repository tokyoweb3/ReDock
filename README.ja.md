# MWM — Mac Window Manager

ShiftIt と Moom Classic にインスパイアされた軽量 macOS ウィンドウマネージャー。キーボードショートカットでウィンドウを半分・4分割などにスナップ。マルチディスプレイのレイアウトを保存・復元し、コンテキストに応じた自動復元が可能です。

## 動作環境

- macOS 14（Sonoma）以降
- アクセシビリティ権限（初回起動時にプロンプト表示）

## ビルド & 実行

```bash
# ビルド、.app バンドル作成、コード署名
bash scripts/bundle.sh

# 起動
open build/MWM.app

# 停止
pkill -f MWM.app
```

## 初回セットアップ

1. `open build/MWM.app` を実行
2. macOS が**アクセシビリティ権限**を求めるので、システム設定 > プライバシーとセキュリティ > アクセシビリティ で許可
3. MWM がメニューバーにアイコン（グリッドアイコン）として表示される

> **リビルド後の注意:** バイナリのハッシュが変わるため、macOS が権限を無効化します。アクセシビリティ設定で MWM を**オフ→オン**に切り替えてください。

## 機能

### ウィンドウスナップ

キーボードショートカットでフォーカス中のウィンドウをスナップ：

| 操作 | デフォルトショートカット |
|------|------------------------|
| 左半分 | Ctrl+Opt+← |
| 右半分 | Ctrl+Opt+→ |
| 上半分 | Ctrl+Opt+↑ |
| 下半分 | Ctrl+Opt+↓ |
| 左上 | Ctrl+Opt+U |
| 右上 | Ctrl+Opt+I |
| 左下 | Ctrl+Opt+J |
| 右下 | Ctrl+Opt+K |
| 最大化 | Ctrl+Opt+Return |
| 中央 | Ctrl+Opt+C |
| フルスクリーン | Ctrl+Opt+F |
| 拡大 | Ctrl+Opt+= |
| 縮小 | Ctrl+Opt+- |
| 次のディスプレイ | Ctrl+Opt+Cmd+→ |
| 前のディスプレイ | Ctrl+Opt+Cmd+← |
| 集中モード | Ctrl+Opt+Z |

すべてのショートカットは **設定 > ショートカット** でカスタマイズ可能です。

### レイアウトの保存 & 復元

現在のウィンドウ配置を保存し、後から復元できます。

**保存：**
1. ウィンドウを好きなように配置
2. メニューバーの MWM アイコン > **レイアウトを保存...** をクリック
3. 含めるウィンドウを選択、モード（アプリ固有 or テンプレート）を選び、保存

**復元：**
1. メニューバーの MWM アイコン > **レイアウトを復元** > レイアウトを選択
2. **復元（アプリを起動）** で未起動のアプリも自動起動して復元

**レイアウトモード：**
- **アプリ固有** — アプリのバンドル ID でウィンドウをマッチ。各アプリを保存位置に復元。
- **テンプレート** — アプリに関係なく、最近使用した N 個のウィンドウに保存位置を適用。

**レイアウトエディター：**
1. **設定 > レイアウト** を開く
2. レイアウトを選択してビジュアルミニマップをプレビュー
3. ミニマップ上でウィンドウをドラッグして再配置、スナッププリセットで正確に配置
4. レイアウト名・モード・ウィンドウリストを編集
5. 変更を個別に保存・リセット

### 自動復元

環境の変化に応じてレイアウトを自動復元：

1. **設定 > レイアウト** を開く
2. レイアウトを選択し、**自動復元** を有効化
3. 現在のディスプレイ構成がトリガーとして保存される
4. トリガーに一致するディスプレイの接続・切断時に自動復元

**コンテキストトリガー：**
- **ディスプレイ構成** — モニターの接続・切断で発火
- **Wi-Fi SSID** — ネットワーク変更で発火（オフィス vs 自宅）
- **複合条件（AND）** — 複数トリガーを組み合わせて精密にマッチ

トリガーが重複するレイアウト間の競合は自動検出され、UI に表示されます。

### 集中モード

最前面のアプリ以外をすべて非表示にし、一つのタスクに集中できます。メニューバーまたはショートカットでトグル。

### インポート / エクスポート

レイアウトを共有・バックアップ：

- **エクスポート：** メニューバー > レイアウトを書き出す...（設定 > レイアウト ツールバーからも可）
- **インポート：** メニューバー > レイアウトを読み込む...（設定 > レイアウト ツールバーからも可）

バージョン付き JSON ファイルとしてエクスポートされます。インポート時、重複名は自動で連番付与され、自動復元トリガーは安全のためクリアされます。

### 診断

最近の復元結果はメニューバーの **最近の復元** に表示されます。復元・スキップ・失敗の各ウィンドウと具体的な理由が確認できます。

### Stage Manager 互換

MWM は Stage Manager を検出し、レイアウトの保存・復元時にストリップウィンドウを自動的にフィルタリングします。

## 設定

メニューバー > **設定...**（Cmd+,）で開く

| タブ | 内容 |
|------|------|
| ショートカット | すべてのキーボードショートカットをカスタマイズ |
| レイアウト | ビジュアルプレビュー・ドラッグエディター・自動復元・インポート/エクスポート |
| 一般 | 言語選択、ログイン時に起動、バージョン情報 |

## トラブルシューティング

### レイアウト保存時に「0 ウィンドウ」

アクセシビリティ権限が有効でない場合に発生します：

1. システム設定 > プライバシーとセキュリティ > アクセシビリティ を開く
2. リストから MWM を見つける
3. **オフ**→**オン** に切り替える
4. 再度保存を試す

リビルドのたびにバイナリの署名が変わるため、この手順が必要です。

### ウィンドウスナップが動作しない

上記と同じ原因 — リビルド後にアクセシビリティ権限の再付与が必要です。

### メニューにショートカットが表示されない

初回起動時にデフォルトが設定されます。空白の場合は、設定 > ショートカット で各レコーダーをクリックしてショートカットを割り当ててください。

### 復元で一部ウィンドウが「失敗」

一部のアプリ（Electron ベースなど）はアクセシビリティの setFrame コマンドに応答しない場合があります。MWM は復元後に各ウィンドウの位置を検証し、失敗を個別に報告します。

## アーキテクチャ

```
Sources/MWM/
  App/              アプリライフサイクル、メニューバー、設定 UI、ローカライゼーション
  Accessibility/    AXUIElement ラッパー、権限
  WindowManagement/ ウィンドウ操作、計算、ディスパッチャー、Stage Manager
  Screen/           ディスプレイ検出、座標変換
  Layout/           保存/復元、トリガー、診断、インポート/エクスポート、自動復元
  Hotkeys/          KeyboardShortcuts 連携
  Focus/            集中モードサービス
  Resources/        ローカライゼーション文字列 (en, ja, zh-Hans, zh-Hant, ko, es, fr, de, pt-BR)
```
