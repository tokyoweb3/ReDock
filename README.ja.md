# MWM — Mac Window Manager

ShiftIt と Moom Classic にインスパイアされた軽量 macOS ウィンドウマネージャーです。キーボードショートカットでウィンドウを半分・4分割などにスナップでき、マルチディスプレイ対応のレイアウト保存・復元、ディスプレイプロファイル連動の自動復元、ワークスペースプリセットまで備えています。

## 動作環境

- macOS 14（Sonoma）以降
- アクセシビリティ権限（初回起動時にプロンプト表示）

## ビルド & 実行

```bash
# ビルド、.app バンドル作成、コード署名
bash scripts/bundle.sh

# 起動
open build/MWM.app

# 停止
pkill -f MWM.app
```

## 初回セットアップ

1. `open build/MWM.app` を実行
2. macOS が **アクセシビリティ権限** を求めるので、システム設定 > プライバシーとセキュリティ > アクセシビリティ で許可
3. MWM がメニューバーにアイコンとして表示される
4. ワークスペース用の標準レイアウト 5 種類（Coding / Research / Review / Meeting / Writing）が自動作成される

> **リビルド後の注意:** バイナリのハッシュが変わるため、macOS が権限を無効化します。アクセシビリティ設定で MWM を **オフ → オン** に切り替えてください。

## 機能

### ウィンドウスナップ

フォーカス中のウィンドウをショートカットで即座に移動・整列できます。

| 操作 | デフォルトショートカット |
|------|------------------------|
| 左半分 | Ctrl+Opt+Cmd+← |
| 右半分 | Ctrl+Opt+Cmd+→ |
| 上半分 | Ctrl+Opt+Cmd+↑ |
| 下半分 | Ctrl+Opt+Cmd+↓ |
| 左上 | Ctrl+Opt+Cmd+1 |
| 右上 | Ctrl+Opt+Cmd+2 |
| 左下 | Ctrl+Opt+Cmd+3 |
| 右下 | Ctrl+Opt+Cmd+4 |
| 最大化 | Ctrl+Opt+Cmd+M |
| 中央 | Ctrl+Opt+Cmd+C |
| フルスクリーン | Ctrl+Opt+Cmd+F |
| 拡大 | Ctrl+Opt+Cmd+= |
| 縮小 | Ctrl+Opt+Cmd+- |
| 次のディスプレイへ移動 | Ctrl+Opt+Cmd+N |
| 前のディスプレイへ移動 | Ctrl+Opt+Cmd+P |
| 集中モード | Ctrl+Opt+Cmd+Z |

すべてのショートカットは **設定 > ショートカット** で変更できます。

**連打切替:**
- 同じ半分系ショートカットを 1 秒以内に続けて押すと、その辺を固定したまま配置が切り替わります
- 左 / 右 / 上 / 下はいずれも `1/2 → 2/3 → 1/3` の順で循環します
- 別アクションを挟むか、タイムアウトを超えると次回は `1/2` に戻ります
- 対象ホットキーでは HUD に解決後の配置名が表示されます
- 待ち時間は **設定 > 一般** から調整できます

### レイアウトの保存と復元

現在のウィンドウ配置を保存し、あとから同じ配置を呼び戻せます。

**保存:**
1. ウィンドウを希望の位置に並べる
2. メニューバーの MWM アイコン > **レイアウトを保存...**
3. 保存対象のウィンドウを選び、モードを選択して保存

**復元:**
1. メニューバーの MWM アイコン > **レイアウトを復元**
2. 保存済みレイアウトを選ぶ

**レイアウトモード:**
- **アプリ固有**: アプリのバンドル ID を使ってウィンドウを対応付け、各アプリを保存位置に復元
- **テンプレート**: アプリに依存せず、最近使ったウィンドウ群に保存した位置を適用

**命名ルール:**
- 名前未入力の新規レイアウトはローカライズ済みの `"My Layout"` 相当名が使われます
- 同名レイアウトがある場合は `(1)`, `(2)` のように自動で連番が付きます

### レイアウトエディター

1. **設定 > レイアウト** を開く
2. レイアウトを選ぶとビジュアルミニマップが表示される
3. ミニマップ上でウィンドウをドラッグして再配置できる
4. レイアウト名、モード、ウィンドウ一覧を編集できる
5. 変更は **保存** と **リセット** を個別に実行できる
6. 未保存の変更がある状態で別レイアウトへ切り替えると Save / Discard / Cancel の確認が出る

**エディター機能:**
- 現在のウィンドウ状態を再スナップショット
- 実行中アプリからウィンドウを追加
- 各ウィンドウの紐付けアプリを変更
- スナッププリセット: `L1/2`, `R1/2`, `T1/2`, `B1/2`, `TL`, `TR`, `BL`, `BR`, `Max`
- 個別ウィンドウの削除

### ディスプレイバリアントとディスプレイプロファイル

1 つのレイアウトに対して、ディスプレイ構成ごとの複数バリアントを持てます。たとえば「会社では 3 画面」「外出先では MacBook 単体」のような構成差を 1 レイアウト内で吸収できます。

- 新しいディスプレイ構成は自動検出され、プロファイルとして保存される
- プロファイル名は **設定 > レイアウト > ディスプレイプロファイル** で変更できる
- レイアウトエディターではプロファイルごとのバリアントを切り替えて編集できる
- 対応ウィンドウが未設定のバリアントでも、対象ディスプレイ形状はプレビューされる

### ワークスペースプリセット

初回起動時に、よくある作業向けのプリセットレイアウト 5 種類が自動作成されます。

| プリセット | 構成 | デフォルトショートカット |
|-----------|------|------------------------|
| Coding | Editor 60% + Terminal 40%上半分 + Browser 40%下半分 | Ctrl+Opt+Cmd+5 |
| Research | Browser 50% + Notes 50% | Ctrl+Opt+Cmd+6 |
| Review | Editor 50% + Terminal 50% | Ctrl+Opt+Cmd+7 |
| Meeting | Browser 最大化 | Ctrl+Opt+Cmd+8 |
| Writing | Editor 70% 中央寄せ + 集中モード | Ctrl+Opt+Cmd+9 |

ワークスペース枠 5〜9 には、**設定 > ショートカット** から任意の保存レイアウトを再割り当てできます。

### 自動復元

ディスプレイ構成の変化に応じて、対応するレイアウトバリアントを自動復元できます。

1. **設定 > レイアウト** で対象レイアウトを選ぶ
2. バリアントピッカーからディスプレイプロファイルを選ぶ
3. そのバリアントで **自動復元** を有効にする
4. 必要なら **アプリを起動** も有効にする
5. 現在のディスプレイ構成が一致したとき、そのバリアントが自動復元される

**バリアント単位の制御:**
- 自動復元はレイアウト全体ではなく、各ディスプレイバリアントごとに設定される
- バリアントごとにアプリ起動の有無も設定できる
- 同じディスプレイプロファイルに対する重複設定は排他制御される

### お気に入りとレイアウトショートカット

- レイアウトを **お気に入り** にすると、メニューバーに直接表示される
- 各レイアウトには専用ショートカットを割り当てられる
- ワークスペース枠 5〜9 とレイアウト個別ショートカットは UI 上で競合解消される
- お気に入り状態のレイアウトは解除するまで削除できない

### ドロップゾーン

- ウィンドウを画面上端のアクティベーション帯までドラッグすると、ランタイムのドロップゾーンが表示されます
- オーバーレイには基本スナップ候補が常に表示されます
- 現在の実装は、組み込みの基本スナップ候補のみに絞っています
- ドラッグ中は、スナップ候補が出る前にアクティベーション帯そのものを可視表示します

### 集中モード

最前面アプリ以外を非表示にし、対象ウィンドウを画面の約 75% サイズで中央に寄せます。終了時には非表示にしたアプリと元のウィンドウ位置を復元します。

### インポート / エクスポート

レイアウトを JSON バンドルとして共有・バックアップできます。

- **エクスポート**: メニューバー > **レイアウトを書き出す...**、または **設定 > レイアウト** のツールバー
- **インポート**: メニューバー > **レイアウトを読み込む...**、または **設定 > レイアウト** のツールバー

インポート時の挙動:
- 各レイアウトには新しい UUID が割り当てられる
- 重複名は自動で別名に調整される
- 自動復元とアプリ起動フラグは安全のためクリアされる
- バンドルのバージョンとスキーマ互換性を検証する

### 診断

最近の復元結果はメニューバーの **最近の復元** に表示されます。

- 直近 10 件をメニュー表示
- 最大 50 件を永続化
- 復元 / スキップ / 失敗ごとの件数と理由を確認可能

### Stage Manager 互換

Stage Manager が有効な場合、ストリップ用ウィンドウを自動で除外して保存・復元処理への干渉を防ぎます。

## 設定

メニューバー > **設定...**（`Cmd+,`）で開きます。

| タブ | 内容 |
|------|------|
| ショートカット | 標準ショートカット、ワークスペース枠 5〜9、レイアウト個別ショートカットの管理 |
| レイアウト | レイアウト編集、お気に入り、ディスプレイバリアント、自動復元、インポート / エクスポート、ディスプレイプロファイル管理 |
| 一般 | 言語選択、ログイン時に起動、バージョン情報 |

## アーキテクチャ

```text
Sources/MWM/
  App/              アプリライフサイクル、メニューバー、設定 UI、ローカライゼーション
  Accessibility/    AXUIElement ラッパー、権限確認
  WindowManagement/ ウィンドウ操作、計算ロジック、ディスパッチャー、Stage Manager 検出
  Screen/           ディスプレイ検出、座標変換、ディスプレイプロファイル
  Layout/           レイアウト保存/復元、バリアント、自動復元、診断、インポート/エクスポート
  Hotkeys/          KeyboardShortcuts 連携、ワークスペース枠、レイアウトショートカット
  Focus/            集中モードサービス
  Resources/        ローカライズ文字列 (en, ja, zh-Hans, zh-Hant, ko, es, fr, de, pt-BR)
```

**主な実装パターン:**
- ストラテジーパターン: ウィンドウ操作ごとに計算クラスを分離
- AX ラッパー: `AccessibilityElement` で安全に Accessibility API を扱う
- 複数ディスプレイ対応復元: ディスプレイ構成に最も近いバリアントを選択
- スコアベースマッチング: `WindowMatcher` がロール、タイトル、位置近似を組み合わせる
- サービスコンテナ: `AppServices` で主要サービスを集約

**保存先:**

```text
~/Library/Application Support/MWM/
  layouts/              レイアウト JSON
  display-profiles.json ディスプレイプロファイル
  diagnostics.json      復元履歴（最大 50 件）
```

## トラブルシューティング

### レイアウト保存時に「0 ウィンドウ」になる

アクセシビリティ権限が無効です。

1. システム設定 > プライバシーとセキュリティ > アクセシビリティ を開く
2. 一覧から MWM を探す
3. **オフ → オン** に切り替える
4. 再度保存を試す

リビルドのたびに署名が変わるため、この手順が必要です。

### ウィンドウスナップが動かない

多くは上記と同じくアクセシビリティ権限の再付与が必要です。

### メニューにショートカットが表示されない

初回起動時にデフォルトは設定されますが、空欄になっている場合は **設定 > ショートカット** で再設定してください。

### 一部ウィンドウの復元が失敗する

Electron 系など一部アプリは Accessibility の `setFrame` に完全対応していないことがあります。MWM は復元後の位置を検証し、失敗理由を診断メニューに記録します。
