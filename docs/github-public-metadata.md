## Short About Text for Social / Launch Posts

ReDock is a lightweight macOS window manager inspired by ShiftIt and Moom Classic. It supports keyboard-driven window snapping, saved layouts, multi-display variants, auto-restore, and workspace presets.

## First Public Release Draft

### Title

ReDock v2.0.0 - First public OSS release

### Body

ReDock is now available as an open-source macOS window manager under the MIT License.

Highlights:

- Keyboard-driven window snapping
- Layout save and restore
- Display-aware layout variants
- Auto-restore for matching display setups
- Workspace presets
- Multi-language support

Current release notes:

- Local build remains the primary supported install path
- GitHub release DMGs are preview-quality until Developer ID signing and notarization are added
- Accessibility permission is required for core functionality
