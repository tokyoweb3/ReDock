# Security Policy

## Supported Versions

Security fixes are provided on a best-effort basis for the latest release on `main`.

## Reporting a Vulnerability

Please do not report security vulnerabilities in public GitHub issues.

Send a private report to the project maintainer with:

- A description of the issue
- Impact assessment
- Reproduction steps or proof of concept
- Suggested mitigation, if available

If you do not yet have a private contact path configured for this repository, set one before public launch, such as a dedicated security email address in the repository profile or README.

## Response Expectations

The maintainer will acknowledge receipt, validate the issue, and coordinate a fix and disclosure timeline when the report is actionable.
