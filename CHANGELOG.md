# Changelog

## v1.0.0 — 2026-03-11

Initial public release as ReDock.

### Features

- **Window snapping** — Halves, quarters, maximize, center, full screen
- **Incremental resize** — Make windows larger/smaller
- **Multi-display** — Move windows between screens
- **Zen Mode** — Hide all except frontmost app
- **Layout save & restore** — Persistent layouts with relative frame positioning
- **Context-aware auto-restore** — Automatically restore layouts when display configuration changes
- **App launch on restore** — Optionally launch missing apps before restoring
- **Stage Manager compatibility** — Detects Stage Manager and filters strip windows
- **Template mode** — Apply saved positions to the N most recently used windows, regardless of app
- **Layout editor** — Drag windows in a visual minimap, snap to presets, edit name/mode
- **Import/Export** — Share layouts as versioned JSON files
- **Diagnostics** — System permission checks and restore result history in settings and menu bar
- **Multi-language support** — 9 languages: English, Japanese, Simplified Chinese, Traditional Chinese, Korean, Spanish, French, German, Brazilian Portuguese
- **Settings** — Customizable shortcuts, layout management, launch at login
- **Menu bar UI** — Quick access to all features with keyboard shortcut display
